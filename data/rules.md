# `meihua.iztro.com` 排盘与标签规则

> 用途：让 GPTs 在用户复制纯文字排盘、或只提供报数与时间时，复现 `https://meihua.iztro.com/` 的显示结果。
>
> 边界：这是对该网站公开前端代码的规则整理，不代表所有梅花易数流派的唯一算法。解释时应称为“网站规则”或“网站标签”。

## 0. 何时采用、何时不采用

- 用户粘贴该网站排盘，或只给一个或多个整数且没有指定其他起卦法时，采用本文件规则。
- 用户明确指定时间起卦、铜钱法、蓍草法、其他平台、其他流派或直接指定上卦／下卦／动爻时，服从用户方法，不套用本文件的报数算法。
- 用户只给最终卦象时，可以用本文件中的六位编码规则校验卦名，但不得自动补上该网站特有的空、库和神煞。
- 手动多动爻不属于该网站报数起卦的单动爻情形，不强制采用本文件的体用规则。

## 1. 最小输入与可推导范围

| 用户提供 | 可以可靠推导 |
|---|---|
| 只有报数 | 本卦、互卦、动爻、变卦、体用 |
| 报数＋网站显示的四柱与各柱旬空 | 上述全部内容，以及默认设置下的空、库、日禄、贵人、桃花、驿马、旺相休囚死、生克 |
| 网站完整复制文本 | 先从报数与时间重建，再用复制出的卦名、标签和生克文字复核 |

纯文字通常足够，不需要图片。仅在以下情况建议补图：用户手动起卦而没有报数、复制文本丢失本互变卦名、用户修改了年／月／日／时基准却未说明，或文字结果彼此冲突。若只有公历时间而没有四柱，优先请用户补贴网站时间表，不要求图片。

只有公历时间时，必须先用可验证的历法工具换算四柱；没有此能力就不得凭记忆硬算。用户从网站复制的文字本身已包含四柱和旬空，因此通常不存在这一缺口。

## 2. 报数解析

网站把输入按非英文字母、非数字字符切分，再要求每个片段可转成数字。因此负号和小数点不会被保留：例如 `-3` 可能被当成 `3`，`1.5` 会被拆成 `1` 和 `5`。GPTs 遇到负数或小数时应请用户确认或改用正整数，不要静默模仿这种拆分。

### 两个数字

设输入为 `A B`：

- 上卦序号：`A mod 8`，余 0 按 8。
- 下卦序号：`B mod 8`，余 0 按 8。
- 动爻：`(A + B) mod 6`，余 0 按 6。

八卦序号：1乾、2兑、3离、4震、5巽、6坎、7艮、8坤。

### 一个数字

同一个数字分别除以 8、8、6，得到上卦、下卦、动爻。因此单数输入会得到相同的上下卦。

### 三个或更多数字

设共有 N 个数字，在 `floor(N/2)` 处分组：

- 前半组之和定上卦；
- 后半组之和定下卦；
- 全部数字之和定动爻。

奇数个数字时，后半组比前半组多一个数字。

### 数值范围

网站没有显式设置最小值或最大值。为了避免 JavaScript 超大整数精度问题，建议使用正整数，日常可限制在 1～999；这是使用建议，不是网站硬限制。

## 3. 六位编码、互卦与变卦

六位编码按卦图从上往下排列：前三位是上卦，后三位是下卦。

| 卦 | 编码 | 五行 | 所含地支 |
|---|---:|---|---|
| 乾 | 111 | 金 | 戌、亥 |
| 兑 | 011 | 金 | 酉 |
| 离 | 101 | 火 | 午 |
| 震 | 001 | 木 | 卯 |
| 巽 | 110 | 木 | 辰、巳 |
| 坎 | 010 | 水 | 子 |
| 艮 | 100 | 土 | 丑、寅 |
| 坤 | 000 | 土 | 未、申 |

设本卦六位码为 `abcdef`：

- 互卦：`bcdcde`，即上互卦取第 2、3、4 位，下互卦取第 3、4、5 位。
- 初爻动：翻转 `f`。
- 二爻动：翻转 `e`。
- 三爻动：翻转 `d`。
- 四爻动：翻转 `c`。
- 五爻动：翻转 `b`。
- 上爻动：翻转 `a`。
- 翻转规则：`0 ↔ 1`。

动爻位于下卦时，下卦为用、上卦为体；动爻位于上卦时，上卦为用、下卦为体。卦图旁的蓝点只标记动爻位置，不是神煞，也不是额外吉凶标签。

## 4. 时间基准

网站生成公历时间、节气、年柱、月柱、日柱、时柱及各柱旬空。默认选择为：

- 旺相休囚死：月支；
- 库：月支；
- 空：日柱旬空；
- 日禄、贵人：日干；
- 桃花、驿马：日支。

网页允许用户点击年、月、日、时改变旺衰、库、空的参照柱。复制成纯文字后，选中状态可能丢失；用户未说明修改时才采用以上默认值。
