# 梅花易数助手

AstrBot 梅花易数排盘与解卦插件。支持直接报数或粘贴排盘文字，本地校验本卦、互卦、变卦与动爻，结合《灵签详解》64 卦知识库生成解读。

提供两种使用方式：

- **`起卦`**：沿用机器人当前的人设与聊天上下文，适合在日常对话中起卦和追问。
- **`完整起卦`（别名 `解卦`）**：使用单独配置的模型，完整输出排盘校验、命中的知识库原文与分层解读；后续用 `问卦` 即可直接追问，无需引用多条回复。

**v0.2.0 · AstrBot >=4.29.4,<5 · Apache-2.0**

## 快速开始

1. **安装插件**：在 AstrBot 插件管理中通过仓库地址安装 `https://github.com/timeance/Astrbot_plugin_meihua`，也可上传仓库 ZIP 或将源码放入 `data/plugins/astrbot_plugin_meihua/` 后重载。无需额外依赖，也不单独保存 API Key。
2. **配置模型**：普通 `起卦` 直接使用当前会话的聊天模型；如需使用独立解卦，在插件配置中选择「独立解卦模型供应商」，推理等级可先保持 `default`。
3. **按需限额**：根据需要设置单用户、单群每日次数与管理员用户 ID，保存并重载插件。
4. **开始使用**：群聊中先通过聊天软件的提及功能 @ 机器人再发送命令，私聊按 AstrBot 的唤醒设置发送：

```text
起卦 报数: 11 12
占问: 这个方案适合先小范围测试吗？
```

> 普通 `起卦` 需要 AstrBot 本地 Agent Runner。使用 Dify、Coze 等第三方 Runner 时，请改用 `完整起卦` 或 `解卦`，并配置独立模型。

## 命令一览

| 命令 | 说明 | 如何追问 |
| --- | --- | --- |
| `起卦 <报数或排盘>` | 返回排盘校验，由当前聊天模型结合知识库解读，沿用人设、历史与已启用的其他插件 | 直接聊天追问 |
| `完整起卦 <报数或排盘>` | 独立输出排盘校验、命中的完整知识库原文与分层解读 | 使用 `问卦` |
| `解卦 <报数或排盘>` | 同 `完整起卦` | 使用 `问卦` |
| `问卦 <补充背景或问题>` | 续接当前会话中自己的最近一次独立解卦，只回答本次问题 | 继续使用 `问卦` |

独立模式只使用当前卦象及本卦问答，不引入日常聊天的人设、记忆或历史，不调用其他插件工具，也不写入日常聊天历史。占问与背景会随请求发送给所选模型服务；额度数据库仅保存次数，不保存正文。

> 示例均省略唤醒前缀；若配置了 `/` 等前缀，请按实际设置添加，例如 `/起卦 11 12`。

## 排盘输入方式

### 直接报数

输入一个或多个正整数，默认采用 [meihua.iztro.com](https://meihua.iztro.com/) 的报数规则。纯数字可直接发送 `起卦 11 12`；附带背景时建议写明「报数」与「占问」。日期、预算等背景数字不会自动作为报数。

```text
完整起卦 报数: 11 12
占问: 新方案应当注意什么？
```

### 粘贴已有排盘

可直接粘贴网站复制的排盘文字，保留字段名即可。支持冒号、空格、制表符或换行，可识别事由、报数、四柱、空亡及本卦、互卦、变卦：

```text
起卦 占问: 新方案适合先小范围测试吗？
时间: 2026年11月22日 17时25分
四柱: 丙午 己亥 庚子 乙酉
本卦: 水泽节
变卦: 坎为水
空亡: 寅卯 辰巳 辰巳 午未
```

- **自动校验**：给出本卦与变卦（或动爻）后无需再报数，插件会自动推导互卦并核对一致性；若同时提供报数与卦象且存在冲突，会提示修正。信息不足时，按提示补齐后重发完整命令。
- **自定义流派**：其他流派或手动排盘请注明「起卦法」或「来源」并给出最终卦象；六位卦码请标注「卦码」以防与报数混淆。
- **输入格式**：目前仅支持文字输入，截图请先转为文字。

## 问卦续接

```text
解卦 报数: 11 12
占问: 新方案应当注意什么？

问卦 补充背景：我计划先小范围测试，预算有限。
问卦 互卦对这个判断有什么影响？
```

- `问卦` 会自动带入原始占问、排盘、完整知识库原文、首次解读及本卦已成功完成的问答，记录按「机器人 + 会话 + 用户」相互隔离。
- 发起新的有效 `完整起卦` 或 `解卦` 时会覆盖旧记录；输入错误、配置异常或超额拦截不会覆盖旧记录。若模型请求失败，新排盘仍会保留，可稍后用 `问卦` 重试。普通 `起卦` 不影响这份独立记录。
- **独立问卦记录保存在内存中，重载插件或重启机器人后会清空**；普通 `起卦` 的上下文随 AstrBot 聊天记录管理。

## 核心配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 独立解卦模型供应商 | 未选择 | 用于 `完整起卦`、`解卦` 与 `问卦`；普通 `起卦` 仍用当前聊天模型 |
| 独立解卦推理等级 | `default` | 沿用供应商设置，或指定 `none` / `minimal` / `low` / `medium` / `high` / `xhigh` |
| 单用户每日次数 | `0` | `0` 为不限；同一平台、同一机器人下跨群与私聊累计 |
| 单群每日总次数 | `0` | `0` 为不限；群成员共享，私聊不受此限制 |
| 管理员用户 ID | 空列表 | 填账号 ID（如 QQ 号）；列表内账号与 AstrBot 全局管理员均豁免限额 |

- **供应商兼容**：独立模式支持 OpenAI 兼容（Chat Completions / Responses）及内置 Anthropic、Gemini 供应商。自定义推理等级仅适配 OpenAI 兼容供应商，Anthropic 与 Gemini 请保持 `default`；模型不支持所选等级时提示失败，不自动降级重试。
- **限额规则**：本插件四个命令共用每日额度，普通成员需同时满足个人与群额度。管理员调用不扣个人或群次数，群管理员身份本身不自动豁免。每次通过检查进入模型解读计 1 次，请求失败、超时或发送失败同样计次；输入无效、无卦可续接、配置检查失败或超额拦截不计次。分段回复及普通起卦同一轮中的工具调用、模型重试不重复扣次。
- **重置与持久化**：额度每日北京时间（UTC+8）00:00 重置，保存在 `data/plugin_data/astrbot_plugin_meihua/quota.sqlite3`，重载或重启不会清零当天次数。普通 `起卦` 后的日常聊天追问不计入插件额度。

## 常见问题

- **为什么独立解卦会分多条回复？** 插件依次发出排盘校验、命中的完整知识库原文和模型解读，长文本也会自动分段；直接发 `问卦` 即可续接全部资料。
- **为什么结果里没有旺衰、空亡等标签？** 仅在符合网站规则且必要字段齐全时计算；仅提供公历时间不会自动换算四柱，也不会核验已有干支与公历是否一致。
- **只返回了排盘，没有模型解读？** 普通 `起卦` 在当前会话关闭 AI 时仅做排盘校验；开启后再试。独立模式请检查插件中的供应商与推理等级配置。
- **回复里会带出 Markdown 符号吗？** 插件会清理本插件解读回复中的标题、加粗、反引号等常见标记，保留正文与段落。

## 从 0.1.x 升级

升级后，原来的独立解卦请改用 `完整起卦`（别名 `解卦`），现在的 `起卦` 会沿用当前聊天的人设与上下文。原有的模型和推理等级配置继续用于独立模式；新增限额默认不限，保存配置并重载即可。详细变更见 [更新日志](CHANGELOG.md)。
